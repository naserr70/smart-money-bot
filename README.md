# Smart Money Bot v2

بازنویسی و ارتقای ربات رصد ورود/خروج پول هوشمند نوبیتکس. دو منبع سیگنال کاملاً
**مستقل** دارد که هرکدام جدا تحلیل و ارسال می‌شوند:

1. **سیگنال تیکر صرافی (Market Signal)** — جهش حجم معاملات ۲۴ ساعته +
   حرکت قیمت، دقیقاً منطق نسخه اول ولی با رفع باگ‌ها (پایین را ببینید).
2. **سیگنال آن‌چین کیف‌پول صرافی (Exchange Flow Signal)** — تازه اضافه شده:
   رصد واریز/برداشت‌های بزرگ به/از کیف‌پول‌های شناخته‌شده صرافی‌ها
   (Binance و...) روی اتریوم/BSC، از طریق Etherscan/BscScan API.

## چرا این معماری؟

کد اصلی یک فایل تک‌قطعه‌ای بود با استیت سراسری بدون قفل، منطق `elif` که می‌توانست
سیگنال را در نقطه مرزی گم کند، و بدون هیچ راه واقعی برای ردیابی نهنگ‌ها به‌جز
حدس زدن از روی حجم تیکر. نسخه‌ی دوم:

- استیت را پشت یک `RLock` می‌برد و بین دو حلقه‌ی پس‌زمینه (مارکت و نهنگ) به شکل
  امن به اشتراک می‌گذارد.
- منطق ورود/خروج را از `elif` به دو شرط مستقل تبدیل می‌کند تا هیچ حالتی گم نشود.
- کوول‌داون‌ها (`last_alert_time`) و دیدوپ تراکنش‌های آن‌چین را روی دیسک ذخیره
  می‌کند تا با ری‌استارت سرویس (رایج در پلتفرم‌هایی مثل Render/Railway) بلافاصله
  هرچی در کوول‌داون بود دوباره فایر نشود.
- هر منبع داده (Binance/KuCoin/Etherscan/CoinGecko) در فایل جدای خودش است تا
  تست و جایگزینی مستقل باشد.

## فایل‌ها

| فایل | مسئولیت |
|---|---|
| `config.py` | خواندن/اعتبارسنجی تمام تنظیمات از Environment Variables |
| `assets.py` | لیست دارایی‌های نوبیتکس + نگاشت نام مستعار بین صرافی‌ها |
| `state.py` | استیت thread-safe + ذخیره/بازیابی روی دیسک |
| `signals.py` | دیتاکلاس‌های سیگنال + قالب پیام تلگرام هرکدام |
| `telegram_notifier.py` | ارسال/حذف/chunk کردن پیام تلگرام |
| `market_data.py` | دریافت تیکر از Binance (fallback: KuCoin) |
| `market_analyzer.py` | منطق تشخیص جهش حجم/قیمت (سیگنال ۱) |
| `price_feed.py` | قیمت USD لحظه‌ای از CoinGecko (برای تبدیل مقدار آن‌چین) |
| `exchange_flow.py` | ردیابی کیف‌پول صرافی روی Etherscan/BscScan (سیگنال ۲) |
| `main.py` | نقطه‌ی ورود: Flask + دو حلقه‌ی پس‌زمینه‌ی مستقل |

## راه‌اندازی

```bash
pip install -r requirements.txt

export BOT_TOKEN="..."
export CHAT_ID="..."
# اختیاری ولی برای فعال شدن سیگنال آن‌چین لازم است (رایگان):
export ETHERSCAN_API_KEY="..."     # https://etherscan.io/apis
export BSCSCAN_API_KEY="..."       # اختیاری، برای پوشش BNB Chain

python main.py
```

`/status` سلامت هر دو حلقه را جدا گزارش می‌دهد (`last_market_cycle_at`,
`last_whale_cycle_at`, `whale_tracker_enabled`, ...).

## تنظیمات مهم اضافه‌شده

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `ETHERSCAN_API_KEY` | - | کلید رایگان Etherscan؛ بدون آن ماژول کیف‌پول غیرفعال می‌ماند (بدون کرش) |
| `WHALE_MIN_USD` | `500000` | حداقل ارزش تراکنش آن‌چین برای فایر شدن سیگنال |
| `WHALE_SCAN_INTERVAL_SEC` | `120` | فاصله‌ی هر بار رصد کیف‌پول‌ها |
| `WHALE_COOLDOWN_SEC` | `900` | کوول‌داون هر (کیف‌پول، توکن، جهت) |
| `EXCHANGE_WALLETS_JSON` | - | افزودن/بازنویسی لیست کیف‌پول‌های رصدشده، مثال پایین |
| `STATE_FILE_PATH` | `bot_state.json` | مسیر فایل ذخیره‌ی کوول‌داون‌ها؛ خالی = غیرفعال |

مثال افزودن کیف‌پول: (آدرس‌ها را همیشه خودتان روی etherscan.io/bscscan.com
راستی‌آزمایی کنید قبل از اعتماد کردن)

```bash
export EXCHANGE_WALLETS_JSON='{"ETH": {"0xYOUR_VERIFIED_ADDRESS": "Coinbase 1"}}'
```

## محدودیت‌های شناخته‌شده (صادقانه، نه پنهان)

- ماژول آن‌چین فقط همان کیف‌پول‌هایی را می‌بیند که در لیست گذاشته‌اید — کامل
  بودن آن به کامل بودن واچ‌لیست شما بستگی دارد؛ سرویس‌های تجاری مثل Whale Alert
  هزاران آدرس لیبل‌شده دارند که این نسخه‌ی رایگان جایگزین کاملشان نیست.
- قیمت توکن‌های آن‌چین از CoinGecko رایگان می‌آید و برای توکن‌های خیلی کم‌شناخته
  ممکن است موجود نباشد؛ در آن حالت به‌جای گزارش عدد غلط، آن تراکنش نادیده گرفته
  می‌شود.
- اندپوینت‌های Etherscan/BscScan ممکن است در طول زمان تغییر کنند — قبل از
  دیپلوی نهایی مستندات فعلی‌شان را چک کنید.
- این ابزار صرفاً یک سیگنال اطلاعاتی است، نه توصیه‌ی سرمایه‌گذاری.
