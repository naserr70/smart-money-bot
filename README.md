# Smart Money Bot v2

بازنویسی و ارتقای ربات رصد ورود/خروج پول هوشمند نوبیتکس. دو منبع سیگنال کاملاً
**مستقل** دارد که هرکدام جدا تحلیل و ارسال می‌شوند:

1. **سیگنال تیکر صرافی (Market Signal)** — جهش حجم معاملات ۲۴ ساعته + حرکت
   قیمت. دو مسیر تشخیص دارد: آستانه‌ی ثابت درصدی (`PRICE_PUMP_MIN/MAX`) **و**
   یک لایه‌ی آماری (z-score نسبت به تاریخچه‌ی حرکات خودِ همون ارز) — بخش
   «تشخیص پامپ» پایین‌تر رو ببین.
2. **سیگنال آن‌چین کیف‌پول صرافی (Exchange Flow Signal)** — رصد واریز/برداشت‌های
   بزرگ به/از کیف‌پول‌های شناخته‌شده‌ی صرافی‌ها روی **اتریوم، BSC، و TRON**.

فهرست دارایی‌های نوبیتکس (`assets.py`) یک لیست استاتیک است که مستقیم از
پیست کردن صفحه‌ی `nobitex.ir/price/` توسط کاربر و پردازش خودکار (نه تایپ
دستی) ساخته شده — هر وقت لیست نوبیتکس عوض شد، کافیه دوباره پیستش کنی.

## سوال ۱: چرا فقط کیف‌پول اتریوم/USDT رصد می‌شه؟

جواب کوتاه: دیگه فقط این نیست. `exchange_flow.py` الان سه زنجیره رو پوشش
می‌ده:

| زنجیره | چی رصد می‌شه | نیازمندی |
|---|---|---|
| ETH | کوین بومی (ETH) + هر توکن ERC-20 | `ETHERSCAN_API_KEY` |
| BSC | کوین بومی (BNB) + هر توکن BEP-20 | `ETHERSCAN_API_KEY` (یا `BSCSCAN_API_KEY` جدا) |
| TRON | توکن‌های TRC-20 (مهم‌ترینش USDT-TRC20 — اکثر جابه‌جایی نهنگ‌های USDT دقیقاً روی همین شبکه اتفاق می‌افته، نه اتریوم) | اختیاری: `TRON_API_KEY` (بدون کلید هم کار می‌کنه، فقط محدودیت نرخ بیشتره) |

**محدودیت‌های صادقانه‌ای که هنوز باقی مونده:**
- **TRX بومی روی ترون رصد نمی‌شه** — فرمت تراکنش خام ترون (`raw_data`) آدرس‌ها
  و مقادیر رو داخل یک بلاک هگز کدگذاری می‌کنه که نیاز به دیکد جداگونه داره؛
  به‌جای حدس زدن فرمتش، این بخش عمداً ناقص گذاشته شده تا وقتی درست پیاده و
  تست بشه.
- **بیت‌کوین، سولانا، و بقیه‌ی زنجیره‌های غیر-EVM/غیر-ترون اصلاً رصد نمی‌شن.**
  هرکدوم API/فرمت آدرس خودشون رو دارن؛ نقطه‌ی الحاق دقیقاً `CHAIN_TYPE` توی
  `exchange_flow.py`ه — وقتی آدرس کیف‌پول تایید‌شده برای یک صرافی روی یک
  زنجیره‌ی خاص داشتی، بگو تا اضافه‌اش کنم (دوباره: حدس زدن آدرس = تکرار دقیق
  اشتباه SYS/SYN، پس عمداً هیچ آدرس تأییدنشده‌ای هاردکد نشده).
- **فقط کیف‌پول‌هایی که خودت لیست کنی رصد می‌شن** — کامل بودنش به کامل بودن
  `EXCHANGE_WALLETS_JSON` بستگی داره، نه اینکه خودکار همه‌چی رو پیدا کنه.

اضافه کردن کیف‌پول ترون:
```bash
export EXCHANGE_WALLETS_JSON='{"TRON": {"Tآدرس_تاییدشده_روی_tronscan": "نام صرافی"}}'
```

## سوال ۲: تشخیص پامپ ممکنه؟

بله، و الان دو لایه داره:

1. **آستانه‌ی ثابت** (همون منطق قبلی): `PRICE_PUMP_MIN` تا `PRICE_PUMP_MAX`
   درصد تغییر قیمت + جهش حجم.
2. **z-score آماری** (جدید): هر ارز نسبت به **تاریخچه‌ی حرکات خودش** (نه یک
   آستانه‌ی یکسان برای همه) سنجیده می‌شه. یعنی ارزی که همیشه آروم حرکت می‌کنه
   با یک حرکت ۰.۸٪ هم می‌تونه فلگ بشه (چون برای اون ارز غیرعادیه)، در حالی که
   یک میم‌کوین که همیشه ۵٪ نوسان داره با همون ۰.۸٪ فلگ نمی‌شه. کنترلش با
   `PUMP_ZSCORE_ENABLED` (پیش‌فرض روشن) و `PUMP_ZSCORE_THRESHOLD` (پیش‌فرض `3.0`
   انحراف معیار).

محدودیت صادقانه: پنجره‌ی تاریخچه کوتاهه (`HISTORY_WINDOW` چرخه، پیش‌فرض ۱۲ تا
= حدود ۱ ساعت با فاصله‌ی ۵ دقیقه‌ای)، پس این یک تشخیص "ناهنجاری کوتاه‌مدت"ه، نه
یک مدل کامل تشخیص الگوی پامپ-و-دامپ چندروزه.

## راه‌اندازی

```bash
pip install -r requirements.txt

export BOT_TOKEN="..."
export CHAT_ID="..."
export ETHERSCAN_API_KEY="..."     # https://etherscan.io/apis (رایگان، برای ETH+BSC کافیه)
export TRON_API_KEY="..."          # اختیاری: https://www.trongrid.io

python main.py
```

## فایل‌ها

| فایل | مسئولیت |
|---|---|
| `config.py` | خواندن/اعتبارسنجی تمام تنظیمات از Environment Variables |
| `assets.py` | لیست دارایی‌های نوبیتکس (استاتیک) + نگاشت نام مستعار بین صرافی‌ها |
| `state.py` | استیت thread-safe + ذخیره/بازیابی روی دیسک + تاریخچه‌ی حجم/بازده قیمت |
| `signals.py` | دیتاکلاس‌های سیگنال + قالب پیام تلگرام هرکدام |
| `telegram_notifier.py` | ارسال/حذف/chunk کردن پیام تلگرام |
| `market_data.py` | دریافت تیکر از Binance (fallback: KuCoin) |
| `market_analyzer.py` | تشخیص جهش حجم/قیمت + z-score آماری (سیگنال ۱) |
| `price_feed.py` | قیمت USD از CoinGecko، با batching و rate-limit protection |
| `exchange_flow.py` | ردیابی کیف‌پول صرافی روی ETH/BSC/TRON (سیگنال ۲) |
| `main.py` | نقطه‌ی ورود: Flask + دو حلقه‌ی پس‌زمینه‌ی مستقل |

## محدودیت‌های شناخته‌شده (صادقانه، نه پنهان)

- ماژول آن‌چین فقط همون کیف‌پول‌هایی رو می‌بینه که در `EXCHANGE_WALLETS_JSON`
  گذاشتید.
- TRX بومی و زنجیره‌های غیر EVM/غیر TRON (بیت‌کوین، سولانا، ...) هنوز پوشش
  داده نمی‌شن — بالاتر توضیح داده شد.
- قیمت توکن‌های آن‌چین از CoinGecko رایگان می‌آد؛ برای توکن‌های خیلی کم‌شناخته
  ممکنه موجود نباشه، در اون حالت اون تراکنش نادیده گرفته می‌شه (به‌جز
  USDT-TRC20 که چون پگش خودِ کارکرد توکنه، پیش‌فرض ۱$ استفاده می‌شه).
- z-score یک پنجره‌ی کوتاه‌مدته، جایگزین قضاوت انسانی نیست.
- این ابزار صرفاً یک سیگنال اطلاعاتی است، نه توصیه‌ی سرمایه‌گذاری.
